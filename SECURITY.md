# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or concern within this repository, please do **NOT** open a public GitHub issue.

Please report vulnerabilities by:
- Using GitHub's [Private Vulnerability Reporting](https://github.com/moruku36/pqc-crypto-inventory-lab/security/advisories/new) feature on this repository.
- Alternatively, contacting the repository maintainer directly via email: `kentaro.mori36@gmail.com`.

### What to Include in Your Report
- Clear description of the potential vulnerability.
- Steps to reproduce or proof-of-concept if available.
- Impact assessment and affected components.

We will acknowledge receipt of your report within 48 hours and work with you on timely triage and coordinated disclosure.
