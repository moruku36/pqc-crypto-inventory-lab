# 正解つき模擬システム

架空の小規模サービスを棚卸しする演習です。実際の接続や暗号処理は実行しません。証明書は自己署名の公開証明書だけを含み、秘密鍵は保存していません。`data/archive.json`に実データはありません。

## 実行

リポジトリのルートで環境を準備した後、次を実行します。

```sh
pqc-scan directory ./samples/mini-service
```

結果を[正解表](../mini-service-ground-truth.json)と照合してください。正解表はスキャン対象フォルダーの外に置き、スキャナーに答えを読ませない構成です。

| 対象 | シナリオ上の用途 | 期待される観測 |
|---|---|---|
| `app/transport.py` | 通信の鍵交換 | Python辞書の値は検出されない |
| `app/signing.py` | 文書署名 | RSAのAPI呼び出しを検出 |
| `certs/service.crt` | サービス証明書 | RSA公開鍵を検出。実際の配備は不明 |
| `config/transport.json` | 通信と保存データの設定 | X25519を1件、AES-256を2件検出 |
| `data/archive.json` | 12年間保持する架空の保存データ | データとAES設定の関係は検出されない |
| `retired/old_signing.py` | 未使用の旧コード | SHA-1を検出。使用中かどうかは判定できない |

## 考えること

1. 検出された6件のうち、実際の運用を確認しないと優先順位を決められないのはどれですか。
2. 2件の未検出例と、未使用コードの検出例は、スキャナーのどの限界を示しますか。
3. 保存データの保持期間が長いという申告を確かめるには、どの運用資料や担当者が必要ですか。

正解表の`runtime`と`role`は演習用の申告です。ツールによる実測・検証結果ではありません。`detected`はこの固定フィクスチャに対する期待値で、[回帰テスト](../../tests/test_mini_service.py)が差異を確認します。
